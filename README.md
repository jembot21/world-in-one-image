One image that sums up the world news of Wednesday 18 November 2026: a one-page newspaper, "The Daily Globe", drawn by an AI agent — Trump lands in Manila for the Quad summit, Ukraine strikes the Crimean Bridge again, Iranian drones hit a U.S. radar in Bahrain, an Indonesian police general is fired in a presidential wiretap scandal, Nvidia posts a $115.8bn quarter as Wall Street slides, Xi and Carney extend Canada–China trade deals, and Voyager 1 nears one light-day from Earth. The program at main.ts copies entry.png to /output/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
